# Placement Preparation Dashboard 🎯
> **Candidate:** Samar Raj · BCA (Data Science / AI-ML)  
> **Target:** Sem 3 → Sem 6 Placement Season Preparation

A modern, phone-friendly, offline-capable placement roadmap and milestone tracker designed specifically for zero-config hosting on **GitHub Pages**.

---

## 🌟 Key Features

- **📱 Mobile-First Responsive Design**: Optimized for phones (iOS Safari, Android Chrome) with touch targets, sticky bottom navigation bar, and dark/light mode toggle.
- **📊 Real-time Progress Tracking**: Interactive circular progress rings for overall curriculum, active semester, and major project milestones.
- **🚀 3 Major Projects Breakdown**: Dedicated tracking for Full-Stack Analytics, Production ML Pipeline, and GenAI/RAG Showpiece.
- **🔍 Live Search & Filter Chips**: Filter tasks by topic (Python, SQL, DSA, ML, System Design, etc.) or completion status in real-time.
- **➕ Custom Task Creation**: Add personal custom tasks to any semester directly from the dashboard.
- **📥 One-Click Export & Backup**:
  - **Export to CSV**: Download complete tabular report with completion dates for Excel or Google Sheets.
  - **Export to PDF**: Clean print-optimized layout ready to save as an executive PDF summary.
  - **JSON Backup & Restore**: Easily transfer your progress between your phone and laptop.
- **⚡ 100% Offline & Local**: Built with zero external build frameworks; state is instantly saved in browser `localStorage`.

## 🚀 How to Publish on GitHub Pages (2 Minutes)

1. Create a repository on GitHub (e.g., `placement-dashboard`).
2. Push this folder's contents to the `main` branch:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Placement Dashboard"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
3. In your GitHub repository:
   - Go to **Settings** > **Pages** (under "Code and automation" in the left sidebar).
   - Under **Build and deployment** > **Branch**, select `main` and root `/`.
   - Click **Save**.
4. Your site will be live in ~60 seconds at:  
   `https://<your-username>.github.io/<your-repo-name>/`
